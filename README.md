# Можливості смартфона

Навчальний застосунок Expo + React Native + TypeScript, який показує доступ до нативних API телефона. Кожна можливість винесена в окремий екран і компонент, а переходи між екранами реалізовані нижньою панеллю навігації.

## Запуск

```bash
npm install
npm run start
```

Відкрийте проєкт на телефоні через Expo Go або запустіть емулятор командою `npm run android` чи симулятор iOS командою `npm run ios`. Камеру, GPS, контакти й датчики найкраще демонструвати на фізичному пристрої; доступність функцій емулятора залежить від його налаштувань.

Перевірки проєкту: `npm run typecheck` та `npm run lint`.

## Навчальні модулі

- **Камера** — запит дозволу та створення фото через `expo-camera`.
- **GPS** — разове визначення координат і точності через `expo-location`; геолокація у фоні не використовується.
- **Телефон** — передавання номера системному номеронабирачу через `tel:` та відкриття SMS через `sms:`. Застосунок не починає дзвінок без підтвердження користувача.
- **Контакти** — після надання дозволу читаються ім’я та номер одного контакту через `expo-contacts`.
- **Датчики** — показ показників акселерометра через `expo-sensors`; підписка знімається при виході з екрана.
- **Батарея** — показ рівня, стану заряджання та режиму енергозбереження через `expo-battery`.
- **Буфер обміну** — копіювання тексту та читання буфера лише після явного натискання кнопки через `expo-clipboard`.

Системні дозволи запитуються безпосередньо перед використанням функції. Для роботи з пристроєм потрібен Expo Go, що відповідає версії SDK, або нативна збірка development build.
